## About this repository

This repo is a running, revisable record of a structured self-study program:

1. **Python fundamentals** (Chapters 1-11 of Python Crash Course)
2. **Data Structures & Algorithms** (arrays, strings, hashing, linked lists, trees, graphs, heaps, DP, and more)
3. **200 LeetCode problems**, distributed by topic and difficulty

Everything here is meant to be **revisited**, not just archived — treat the `notes/` folder like chapters in a book you re-read, and the `code/` folder like a lab notebook of everything actually written and tested.

## How to use this for revision

- Start with `notes/03_roadmap.md` to see the big picture and where a given week fits.
- `notes/pattern_recognition_notebook.md` is the single most useful file for interview prep later — it maps problem clues to patterns.
- `progress/dashboard.md` always reflects the current, real state — not a template.
- `tracker/leetcode_tracker.csv` is the ground truth for what's actually been solved vs. attempted.
